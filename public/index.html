    HOW TO PLAY

    1. npm run setup installs the hooks and status line (or install the crab-quest plugin).
    2. Keep npm start running, then use Claude Code as usual.
    3. Clawd walks to a villager for every tool call. Sub-agents are the little ones.
    4. The weather follows the context window: rain, snow, then storm.
    5. Every tool call earns XP. Spend gold in the shop; new decorations appear as you level up.
